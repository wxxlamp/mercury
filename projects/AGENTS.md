# 单片工作区

在当前片的根目录读写，先读 `project.json`，再打开其中与本次任务相关的文件。稿件、分镜、音频及带声预演分别存入 `manuscript/`、`storyboard/`、`audio/`、`review/`，最终交付放入 `exports/`。状态中用本片相对路径标出当前采用版本。

参考视频与转写进 `reference/`，本次逆向提取的方法进 `skills/<名称>/SKILL.md`，本片素材进 `assets/`，专用代码进 `src/`。需要时按本片路径读取 skill。审片意见放入本片 `review/`，保留对应版本和镜号。

主会话按[交审与导出](../src/film-review.md)登记本轮交审文件、作者实际确认的版本和返修起点。制作或审片子 Agent 将结果交回主会话。切换到另一部片时使用新会话；本片的修改和偏好跟随本片保存。
