# Mercury 单片导演

根目录新对话收到文稿时，先按[根目录接稿约定](../../../AGENTS.md)自动建片，在同一对话读取单片约定。续作时定位原片。先读本片的 `project.json`、当前采用版本及本轮意见。确认观众、主问题和本次交付。项目目录中的路径均相对本片，本文中的制作手册相对本 skill。按[交审与导出](../../../src/film-review.md)提交每一版，只在作者明确同意后登记批准。

| 目前有什么 | 本轮做什么 | 交给作者判断什么 |
| --- | --- | --- |
| 原稿或有修改意见的稿件 | 按[文稿与段落](references/manuscript.md)形成可念的稿与证据备注，保留原稿和稳定的稿段编号。 | 事实、个人语气、论点范围。作者确认后进入分镜。 |
| 已审稿 | 先说清本段的观看难点，再从[剪辑技巧索引](../../../explore/index.md)选对应的 skill 或作品。按[连续分镜](references/direction.md)写镜头剧本，制作关键帧与全段静音动态预演。 | 观众何时知道什么、视线怎样移动、哪一步仍看不懂。此时用原句定位，所有秒数标为估时。 |
| 已审画面 | 用作者提供的音色样本和本次可用的合成后端试读、录制、对齐。按[声音与终审](references/sound-review.md)交完整口播、干净字幕及全长低清带声预演。 | 声线、停顿、文字可读性、拟音与音乐听感。缺样本或后端时，保留已审分镜并指明依赖。 |
| 作者明确确认了某版带声预演 | 绑定该版素材、时间线、声轨与字幕后导出。实际检查交付文件，记录验证结果。 | MP4、SRT、干声和可重渲工程。 |

**按镜头任务选择技巧。** 观众跟丢对象，先查索引的「叙事与分镜」；对象位置清楚但细节看不清，查「构图、运镜与素材」；跟不上口播或拟音抢话，查「配音、节奏与声音」；定位作者反馈，查「预演、审片与返修」。选定后，在本片分镜写一句“这段为什么用它、看预演时怎么判”。例如截图上的数值读不完，先试停稳并延长阅读时间，连看前后两镜后再决定是否推近。只有需要对标特定镜头、实作或核查时，才进入选中的目录查原件，并在本片记录实际采用的文件、时码或版本。作者明确指定作品时直接从该作品开始。[参考片逆向方法](references/sources.md)

根资料库中的新做法先引用原件，供作者 Review。公共调研候选留在 `explore/`；本片试出的做法留在本片 `skills/`，对应镜号和效果记在本片 `review/`。仅在作者审阅具体条目并明确选择纳入后，再整理进公共 skill。文稿、分镜或成片获批只记录对应作品版本。

主会话持有全片结构和作者审批，可把有清楚边界的段落交给制作角色。遵循[项目交接与返修](references/handoff.md)恢复版本、派发任务、限定重审范围。制作中的素材、代码、方法和反馈留在本片。结项后只按作者明确选择的范围纳入公共层。
