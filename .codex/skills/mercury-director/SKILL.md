# Mercury 单片导演

先读作者指定项目的 `project.json`、当前采用版本及本轮意见。确认观众、主问题和本次交付。项目目录中的路径均相对本片，本文中的制作手册相对本 skill。每轮只提交作者此刻能判断的内容。

| 目前有什么 | 本轮做什么 | 交给作者判断什么 |
| --- | --- | --- |
| 原稿或有修改意见的稿件 | 按[文稿与段落](references/manuscript.md)形成可念的稿与证据备注，保留原稿和稳定的稿段编号。 | 事实、个人语气、论点范围。作者确认后进入分镜。 |
| 已审稿 | 选择匹配本期的参考，按[参考资料的选用与逆向](references/sources.md)读对应原件。按[连续分镜](references/direction.md)写镜头剧本，制作关键帧与全段静音动态预演。 | 观众何时知道什么、视线怎样移动、哪一步仍看不懂。此时用原句定位，所有秒数标为估时。 |
| 已审画面 | 用作者提供的音色样本和本次可用的合成后端试读、录制、对齐。按[声音与终审](references/sound-review.md)交完整口播、干净字幕及全长低清带声预演。 | 声线、停顿、文字可读性、拟音与音乐听感。缺样本或后端时，保留已审分镜并指明依赖。 |
| 作者明确确认了某版带声预演 | 绑定该版素材、时间线、声轨与字幕后导出。实际检查交付文件，记录验证结果。 | MP4、SRT、干声和可重渲工程。 |

作者要求“照这段做”“用完整版选声音”或指定某个来源时，打开本机相应原片、转写或技能脚本，再决定怎样用。有根资料库时，分镜阶段优先选与本期难点最接近的段落对标。只带走 skill 时可以按内置方法出稿、设计镜头和组织审片；还原具体参考的机位、复用其源码或调用完整版工具，需要相应的原件与执行环境。详细入口和缺件处理见[资料表](references/sources.md)。

主会话持有全片结构和作者审批，可把有清楚边界的段落交给制作角色。遵循[项目交接与返修](references/handoff.md)恢复版本、派发任务、限定重审范围。制作中的素材、代码、方法和反馈留在本片。结项后只按作者明确选择的范围纳入公共层。
