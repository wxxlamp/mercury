# 将参考片的做法用于本片

从[剪辑技巧索引](../../../../explore/index.md)按问题选一个 skill、课程或作品。先写清要借的关系，例如“让两次操作看得出是同一笔业务”，再决定需要看哪段原片、哪段讲解或哪份源码。

连播动作前、发生时和落点之后，记下视线、对象身份、构图变化、停顿和声音落点。教程有口述时对照转写，分开记录作者明确讲的内容与自己的画面判断。需要贴近原片时，用相同画幅比较几个关键帧的起止位置、遮挡和持续时间。只借用叙事方法时，可以用本片对象替换原例，先做一段静音预演验证。

本片的分镜或审阅记录中写明采用的技巧、实际依据、改动与验收问题。新添的参考视频或转写进本片 `reference/`，反复用到的方法进本片 `skills/`。缺对标原片、源码或可听音频时，明确本轮能验证什么，给相应镜头保留待核项。
