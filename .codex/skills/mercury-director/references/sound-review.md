# 用本人音色对齐镜头，并终审可导出的版本

**试读与对齐。** 分镜确认后，取一段同时有专名、重音和情绪转折的已审稿试读，记下参考音色、读法、语速与适合的停顿。按连续语义合成或录制，保留句末气口。检查漏字、数字单位和人名。选定 WAV 后转写或强制对齐，以作者确认的优化稿核字，以实录校正断句与入点；项目里的 SRT 只含应展示的文字。画面注释通过稿段或字幕编号另存。按[配音与字幕入口](../../../../src/film-voice.md)先试读，再按句生成或复用实录，试听并校正字幕。

**同一事件驱动声和画。** 例如 M04 的第二封信有“发出”和“抵达”两个事件。只有抵达的轻响承担提示时，将声音绑定接触帧，留给旁白重音空间。镜内事件在 1.20 秒、镜头从素材的 0.20 秒开始用、全片入点为 12.00 秒，正常速度下响在全片 13.00 秒。前镜延长后让事件随镜头移动。变速、改裁切或重录后，从新时间线重新核对。

**选声音与混音。** 旁白、音乐、拟音各留分轨。UI 开关优先试听同一套界面音，真实物件优先按材质、动作、时长找实录，节奏或音高需要精确控制时用程序合成。评分和下载量用于筛选；把两个候选放到同一版画面和旁白里等响比较。先让人声读得清、在关键句下压音乐，再处理突出的齿音、撞击峰值和尾响。记录采用素材及许可。使用作者的完整版检索或混音工具时从[剪辑技巧索引的声音部分](../../../../explore/index.md#配音节奏与声音)选择对应 skill 目录。

**交给终审。** 交整条干声、干净 SRT、全长低清带声预演和版本号。静音检查画面的因果，正常速度听说话、音乐和拟音，再缩到手机尺寸看证据和字幕。按[媒体制作入口](../../../../src/film-media.md)用同一时间线交带声预演。意见落在“版本 / 镜号 / 台词或秒点 / 画面区域 / 看到听到什么 / 期望变化”。把实测与待作者判断的项目分开写。

**按反馈定位返修。** 改一个专名，重录本语义段，校对字幕并检查后续偏移、对口和声画接点。换同尺寸截图，核对裁切框、文字和进入退出时的焦点。把揭示顺序前移，重审相邻镜的起止状态，交还受影响的分镜和带声预演。只调音乐增益，可直接重混并对比同位置听感。审批随具体版本记录。

**导出。** 终审通过后用获批的时间线、素材、音轨和字幕渲染。用 ffprobe 核对容器、画幅、音轨和总时长；解码最终文件，检查开头、跨镜交接、字幕最后一句和音频尾部。若交付带响度指标，测最终编码文件。尚未完成实际试听时标明待听片段。
